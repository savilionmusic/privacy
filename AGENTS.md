# Privacy page working instructions

This repository is the public privacy policy for the herm app, served at https://savilionmusic.github.io/privacy/ from `index.html` on `main` via GitHub Pages.

- Edit `index.html` only; keep it a single self-contained static page.
- The repository is public. Keep anything private out of it.
- `publish.sh` creates the public repo and enables Pages on first use. Do not run it again unless the repo is gone.
- Changing policy wording changes what the user tells people about their data, so confirm the new wording with the user before pushing.
- Project memory: Hindsight bank `coding-agent::Privacy`.
